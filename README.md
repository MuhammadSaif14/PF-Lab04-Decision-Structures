# PF Lab 04 – Decision Structures

This repository contains my solutions for **Lab#04** of the course **CL-1002 Programming Fundamentals** (FAST-NUCES, Fall 2026), taught by Sir Muhammad Aais Rabbani.

All programs are written in **C** and use only `if`, `if/else`, nested `if/else`, and `if/else if/else` ladders (no loops, arrays, switch/case, or ternary operator, as per lab instructions).

## Programs Included
1. **Leap Year Checker** – checks if a given year is a leap year using nested if/else.
2. **Triangle Validity and Type** – checks if 3 sides form a valid triangle and classifies it as Equilateral, Isosceles, or Scalene.
3. **Locate a Point on Cartesian Plane** – finds which quadrant/axis/origin a point (x, y) lies on.
4. **BMI Category Classifier** – calculates BMI and classifies it as Underweight, Normal, Overweight, or Obese.
5. **Largest of Three Numbers** – finds the largest of three numbers using nested if/else only.
6. **The Watermelon Split** – checks if a watermelon of weight `w` kg can be split into two positive even-weight pieces.

## How to Run
```bash
gcc filename.c -o output
./output
```
